# 常量练习任务

完成以下 4 个任务，理解常量和 iota 的用法。

---

## 任务 1：基础常量声明

**需求**：
创建一个函数 `basicConstants()`，声明以下常量并打印：
- 公司名称："TechCorp"
- 最大用户数：1000
- 圆周率：3.14159
- 是否启用调试模式：true

**预期输出**：
```
公司: TechCorp
最大用户数: 1000
圆周率: 3.14159
调试模式: true
```

**提示**：
- 常量使用 `const` 关键字声明
- 常量必须在编译时确定，不能是运行时计算的值
- 可以一次声明一个，也可以用括号声明一组

---

## 任务 2：iota 枚举（星期）

**需求**：
使用 `iota` 创建星期枚举，然后在函数 `weekdayExample()` 中：
1. 声明常量：Sunday=0, Monday=1, ..., Saturday=6
2. 创建一个变量 today，赋值为 Wednesday
3. 打印 today 的值（应该是 3）

**预期输出**：
```
今天是星期: 3 (Wednesday)
```

**提示**：
- `iota` 是 Go 的常量计数器，从 0 开始自动递增
- 在 const 块中，每出现一次 iota，它就代表当前行的位置（从0开始）
- 语法：
  ```go
  const (
      Sunday = iota  // 0
      Monday         // 1
      Tuesday        // 2
      ...
  )
  ```

## 任务 3：iota 跳过值

**需求**：
创建一个表示文件权限的枚举，使用 `iota` 和位运算：
- ReadPermission = 4 (二进制 100)
- WritePermission = 2 (二进制 010)  
- ExecutePermission = 1 (二进制 001)

在函数 `permissionExample()` 中：
1. 声明这些权限常量（使用 iota 和位移运算）
2. 组合权限：ReadWrite = Read | Write
3. 打印各个权限的值

**预期输出**：
```
读权限: 4
写权限: 2
执行权限: 1
读写权限: 6
```

**提示**：
- 可以用 `1 << iota` 来生成 2 的幂次：1, 2, 4, 8...
- 但这个任务要求倒序：4, 2, 1
- 可以使用 `4 >> iota` 或者 `1 << (2-iota)`

## 任务 4：常量表达式计算

**需求**：
创建一个函数 `sizeCalculations()`，声明以下常量并计算：
1. KB = 1024（字节）
2. MB = 1024 * KB（使用常量 KB 计算）
3. GB = 1024 * MB（使用常量 MB 计算）
4. 声明一个变量 fileSize = 5（表示 5GB）
5. 计算并打印该文件占用多少字节

**预期输出**：
```
1 KB = 1024 字节
1 MB = 1048576 字节
1 GB = 1073741824 字节
5 GB = 5368709120 字节
```

**提示**：
- 常量可以参与编译时计算
- 常量表达式的结果也是常量
- 注意：变量 fileSize 和常量相乘，结果是变量
