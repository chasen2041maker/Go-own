## 任务 1：变量声明的三种方式

**需求**：
创建一个函数 `declareVariables()`，在里面使用三种不同的方式声明变量：
- 方式1：使用 `var` 关键字并指定类型
- 方式2：使用 `var` 关键字但让 Go 自动推断类型
- 方式3：使用短变量声明 `:=`

每种方式声明一个字符串变量，并打印出来。

**预期输出**：
```
方式1: 显式声明
方式2: 自动推断
方式3: 短声明
```

**提示**：三种方式的语法分别是 `var name string = ...`、`var name = ...`、`name := ...`

## 任务 2：零值的理解

**需求**：
创建一个函数 `showZeroValues()`，声明以下类型的变量但**不初始化**，然后打印它们的零值：
- `int`
- `float64`
- `string`
- `bool`

**预期输出**：
```
int 的零值: 0
float64 的零值: 0
string 的零值: 
bool 的零值: false
```

**提示**：Go 中所有变量都有默认的"零值"，不会是未定义的。

## 任务 3：类型转换计算

**需求**：
创建一个函数 `calculateAverage()`，完成以下操作：
1. 声明三个 `int` 类型的变量：a=10, b=20, c=25
2. 计算它们的平均值（注意：平均值应该是浮点数）
3. 将结果保存到 `float64` 类型的变量中
4. 打印结果，保留两位小数

**预期输出**：
```
平均值: 18.33
```

**提示**：
- 整数相加再除以整数，结果还是整数（会截断小数）
- 需要将至少一个操作数转换为 `float64`
- 使用 `fmt.Printf("%.2f", value)` 可以格式化小数位数

## 任务 4：多变量声明与交换

**需求**：
创建一个函数 `swapAndPrint()`，实现：
1. 使用**一行代码**同时声明两个变量：x=100, y=200
2. 打印交换前的值
3. 使用**一行代码**交换 x 和 y 的值（不使用临时变量）
4. 打印交换后的值

**预期输出**：
```
交换前: x=100, y=200
交换后: x=200, y=100
```

**提示**：
- Go 支持多重赋值：`a, b := 1, 2`
- 交换可以用：`x, y = y, x`（Go 会先计算右边所有值，再赋值）
