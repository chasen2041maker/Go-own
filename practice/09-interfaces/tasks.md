# 接口练习任务

完成以下 4 个任务，掌握接口定义、实现、类型断言和空接口。

---

## 任务 1：定义和实现接口

**需求**：
定义一个 `Shape` 接口，包含两个方法：
- `Area() float64` - 计算面积
- `Perimeter() float64` - 计算周长

实现两个结构体：

**Circle**（圆形）：
- Radius (float64) - 半径
- 实现 Area()：π × r²
- 实现 Perimeter()：2 × π × r

**Rectangle**（矩形）：
- Width, Height (float64)
- 实现 Area()：宽 × 高
- 实现 Perimeter()：2 × (宽 + 高)

测试：创建圆形（半径5）和矩形（4×6），打印它们的面积和周长。

**预期输出**：
```
圆形: 面积=78.54, 周长=31.42
矩形: 面积=24.00, 周长=20.00
```

**提示**：
- 接口定义：`type Shape interface { ... }`
- Go 的接口是隐式实现的（不需要 implements 关键字）
- 使用 `math.Pi` 获取圆周率

## 任务 2：接口作为参数

**需求**：
创建一个函数 `printShapeInfo(s Shape)`：
- 接受任何实现了 Shape 接口的类型
- 打印它的面积和周长

在 main 中用 Circle 和 Rectangle 测试这个函数。

**预期输出**：
```
面积: 78.54, 周长: 31.42
面积: 24.00, 周长: 20.00
```

**提示**：
- 这就是多态：一个函数可以处理多种类型
- 函数不需要知道具体类型，只需要知道它实现了接口

## 任务 3：类型断言和 type switch

**需求**：
创建一个函数 `describe(i interface{})`：
- 使用 type switch 判断参数的具体类型
- 针对不同类型打印不同的信息：
  - Circle：打印 "这是一个圆形，半径=X"
  - Rectangle：打印 "这是一个矩形，宽=X, 高=Y"
  - int：打印 "这是一个整数: X"
  - string：打印 "这是一个字符串: X"
  - 其他：打印 "未知类型: T, 值=V"

测试：传入 Circle, Rectangle, 42, "hello"

**预期输出**：
```
这是一个圆形，半径=5.00
这是一个矩形，宽=4.00, 高=6.00
这是一个整数: 42
这是一个字符串: hello
```

**提示**：
- `interface{}` 是空接口，可以接受任何类型
- type switch 语法：
  ```go
  switch v := i.(type) {
  case Circle:
      // v 的类型是 Circle
  case int:
      // v 的类型是 int
  }
  ```

## 任务 4：空接口

**需求**：
创建一个函数 `printAnything(value interface{})`：
- 打印参数的类型和值
- 格式：`类型: T, 值: V`

测试不同类型：字符串、整数、浮点数、布尔值、切片。

**预期输出**：
```
类型: string, 值: Go语言
类型: int, 值: 123
类型: float64, 值: 3.14
类型: bool, 值: true
类型: []int, 值: [1 2 3]
```

**提示**：
- `%T` 格式化符号打印类型
- `%v` 格式化符号打印值
- 空接口是 Go 实现泛型功能的基础（Go 1.18 之前）
