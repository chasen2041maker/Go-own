## 练习命名

每个主题下继续创建编号目录，并让目录名直接表达练习内容：

```text
01-基础语法/
  README.md
  01-hello/
    README.md
    main.go
    main_test.go
```

目录名全部使用中文。由于 Go module 不接受含中文的包导入路径，运行某个练习时，从项目根目录执行 `go run .\learn\主题目录\练习目录\main.go`；测试时把源码文件和测试文件一起传给 `go test`。
